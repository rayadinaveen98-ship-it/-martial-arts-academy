# 03 — Instructor demonstration quality gates

**Critical policy: Technical truth beats visual beauty.**

## Asset classes
1. `concept-only`: cinematic or illustrative character, **never** shown as confirmed correct instruction.
2. `reference-licensed`: permitted real-trainer reference media; rights and attribution recorded.
3. `technical-review-pending`: candidate instructional motion; cannot be released as vetted.
4. `approved-instructional`: qualified coach has reviewed motion and teaching context for the named technique and exact version.

No animated character, skeletal rig, AI-generated pose, mirrored video, or generic motion-capture file can be promoted to `approved-instructional` solely by visual inspection.

## Per-asset record
- `assetId`, `revision`, `discipline`, `techniqueId`
- `stanceOrientation`, `cameraView`, `speed`, `license`, `sourceLink`
- `reviewerName`, `reviewerCredential`, `reviewDate`, `reviewStatus`
- `reviewNotes`, `knownLimitations`, `approvedUsage`

## Visual / technical QC
- Anatomy and limb proportions remain stable in all frames.
- Hands, elbows, shoulders, hips, knees and feet transition plausibly.
- Balance, floor contact and stance width stay coherent throughout movement.
- Correct relationship of lead/rear foot and hand for both orientations.
- Guard and recovery are not discarded for visual flair.
- Clear silhouette from each enabled viewing angle.
- No unexplained teleportation, clipping, twisting or orientation reversal.
- Reviewed sequence, speed changes and keyframe stills convey the **same** technique.

## Qualified review checklist
The coach assesses: initial stance, guard, movement phases, weight transfer, range of motion, balance, recovery, basic errors, safety cues and whether visual / voice/text guidance match the asset.

Fail = return to production. Pass = named sign-off with exact version.

## Fallback
If qualified technique review or permitted footage is unavailable, build S2 using text explanations and clearly labelled non-instructional placeholders. **Do not invent flawless martial arts demonstrations.**

## Rights / ethics
Record ownership, production model and permitted distribution of any recorded or sourced footage. Never reuse governing-body manual photos/illustrations without appropriate permission.
